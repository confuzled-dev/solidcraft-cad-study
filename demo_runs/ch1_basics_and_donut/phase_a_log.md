# Phase A Validation Log — `1.0 The Basics` (SolidCraft vs. Autodesk Fusion)

- **Target App:** SolidCraft `v0.45.0` (`https://app.solidcraft.io/`)
- **Viewport:** `1280x720` (desktop web canvas)
- **Reference Plan:** `step_plan.md` — Phase A (`1.0 The Basics`)
- **Date Tested:** 2026-11-21
- **Fusion Navigation Preset:** Present and **active by default** (`Preferences > INPUT > Navigation > Mouse mapping: Fusion`)

---

## Rating Rubric
- **GREEN (Seamless):** Same name/concept, obvious in UI.
- **YELLOW (Minor Translation):** Works cleanly, but renamed, relocated, or extra clicks needed (includes **Book Rewrite** for a SolidCraft edition).
- **RED (Beginner Blocker):** Missing feature or broken workflow.

### Key Takeaways for Beginners & Developers
1. **Strong Fusion Muscle-Memory Compatibility:** SolidCraft defaults to **`Mouse mapping: Fusion`**, **`Z up`**, **`mm` units**, **`Orthographic` projection**, **`Performance` graphics preset**, **`Shaded with edges`**, **`Project face edges into new sketches`**, and **`The first dimension scales the drawing`**—meaning a Fusion beginner's core viewport and sketch defaults work immediately without setup friction.
2. **Primary Translation Gaps (`YELLOW`):** Most friction comes from **menu relocation and naming** rather than broken features (`Timeline` -> `History`, `Create`/`Modify` inside `Model` while `Assemble`/`Insert`/`Inspect` are ribbon tabs and `Select` is inside `View`, `Display` split between Cube and Sliders popovers on the floating Navigation Bar, `XZ`/`XY`/`YZ` plane labels instead of `Front`/`Top`/`Right`, and `Axis Gizmo` instead of `ViewCube`).
3. **Hard Missing Areas (`RED`):** Cloud collaboration (`Hub`, `Data Panel`, `V# Version History`), fixed-spacing `Grid & Snaps` (`50 mm / 5`), `Photobooth` / Design-mode `Environment` switcher, and in-browser `Assistant` chat (desktop app required) are absent on `app.solidcraft.io`.
